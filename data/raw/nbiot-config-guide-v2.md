# Настанова з конфігурації NB-IoT (версія 2)

## Що змінилося порівняно з версією 1
Оновлено TAC та індекс резервування RB для In-Band; скасовано ручну активацію соти.

## Режими розгортання
Для діапазону 900 МГц використовується режим In-Band, для 1800 МГц — режим Guard Band.

## Параметри
| Параметр | In-Band 900 | Guard Band 1800 |
|---|---|---|
| TAC | 41020 | 41020 |
| Індекс резервування RB | 22 | 90 |
| Потужність RS | 15,2 дБм | 15,2 дБм |
| Режим антен | як у host LTE соти | завжди 2T2R |

## Активація
Окрема команда активації соти не виконується: сота активується автоматично після створення.

## Обмеження
Guard Band неможливий, якщо host LTE 1800 працює на Massive MIMO радіомодулі.
