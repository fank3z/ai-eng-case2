# Настанова з конфігурації NB-IoT (версія 1)

## Режими розгортання
Для діапазону 900 МГц використовується режим In-Band, для 1800 МГц — режим Guard Band.

## Параметри
| Параметр | In-Band 900 | Guard Band 1800 |
|---|---|---|
| TAC | 41001 | 41001 |
| Індекс резервування RB | 19 | 90 |
| Потужність RS | 15,2 дБм | 15,2 дБм |

## Активація
Після створення соти виконується команда активації соти вручну.
