# Довідник KPI радіомережі

## Основні KPI
| KPI | Визначення | Цільове значення |
|---|---|---|
| CSSR | Частка успішних встановлень з'єднань | не менше 99,0 % |
| CDR | Частка обірваних з'єднань | не більше 0,5 % |
| HOSR | Частка успішних хендоверів | не менше 98,0 % |
| Availability | Доступність соти без урахування планових робіт | не менше 99,7 % |
| PRB Utilization | Завантаження фізичних ресурсних блоків LTE | не більше 80 % в годину пік |

## Як рахується доступність
Доступність рахується погодинно. Час планових робіт, погоджених через Change Management, з розрахунку виключається.

## Пороги для ескалації
Якщо CDR соти перевищує 2 % протягом трьох годин поспіль, сота передається групі RF-оптимізації.
