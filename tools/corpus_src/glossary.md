# Глосарій NOC

## Терміни
- **NOC** — центр керування мережею, що працює цілодобово.
- **RRU** — віддалений радіомодуль, встановлюється біля антени.
- **BBU** — модуль обробки сигналу в основній смузі.
- **Holdover** — режим, у якому станція тримає частоту без зовнішнього джерела синхронізації.
- **LVD** — пристрій відключення навантаження при низькій напрузі АКБ.
- **Change** — погоджена зміна в мережі з оцінкою ризику.
- **MTTR** — середній час відновлення після аварії.
- **NB-IoT** — вузькосмугова технологія для IoT-пристроїв.

## Скорочення рівнів пріоритету
Critical, Major, Minor, Warning — див. політику класифікації аварій.
