# SOP — Втрата GPS-синхронізації

## Ознаки
Аварія External Clock Reference Problem або GPS Antenna Fault. Базова станція переходить у режим holdover і підтримує частоту за рахунок внутрішнього генератора.

## Час holdover
Для FDD-технологій (GSM, UMTS, LTE FDD) станція може працювати в holdover до 72 годин без суттєвого впливу. Для TDD (NR 3500) допустимий час holdover лише 8 годин, після чого зростає інтерференція з сусідніми сотами.

## Дії
1. Перевірити стан GPS-антени та кабелю в журналі аварій.
2. Якщо на сайті доступна синхронізація PTP, перевести станцію на PTP як резервне джерело.
3. Для NR 3500 створити тікет з пріоритетом major, для FDD-only — minor.
4. Виїзд для заміни GPS-антени планується протягом 24 годин для NR-сайтів і протягом 5 робочих днів для FDD-only сайтів.
