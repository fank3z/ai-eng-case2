# Каталог аварій — радіочастотна частина

## Аварії
| Код | Назва | Пріоритет за замовчуванням |
|---|---|---|
| 26529 | RF Unit VSWR Threshold Crossed | Minor |
| 26235 | RF Unit Maintenance Link Failure | Major |
| 26522 | RF Unit RX Channel RTWP/RSSI Unbalanced | Minor |
| 26530 | RF Unit ALD Current Out of Range | Warning |
| 26262 | External Clock Reference Problem | Minor |

## Примітка
Аварія 26522 означає різницю рівня шуму між приймальними гілками більше 6 дБ; найчастіша причина — волога в конекторі.
