# Changelog промптів

## rag v2 — 2026-11-22
**Що змінено порівняно з v1**
- Явна заборона знань «від себе» і правило not_found навіть для дотичної інформації.
- Правила для скасованих версій документів і для суперечностей між джерелами.
- Вимога атомарних тверджень (claims) з посиланням лише на те джерело, де факт прямо написаний.
- Точне перенесення чисел/кодів, обмеження довжини відповіді.

**Чому** — ⚠️ гіпотези до першого прогону; після `make eval` замініть на факти з `evals/results/`:
- без правил модель схильна відповідати на питання поза корпусом із загальних знань (пастки «немає відповіді»);
- без маркування версій модель бере значення зі скасованої настанови NB-IoT / стандарту 2023;
- без вимоги атомарних claims цитати ставляться «в кінці абзацу» і faithfulness неможливо перевірити.
